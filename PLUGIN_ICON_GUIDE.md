# 插件图标书写规范

插件 `plugin.json` 和 UI JSON 中所有 `icon` 字段都必须遵循本规范。

## 书写规则

- **推荐使用全小写蛇形命名（snake_case）**，例如 `skip_next`、`folder_open`、`rocket_launch`。
- 不要写 `Icons.skip_next`，也不要写 Dart 常量名。
- 兼容自动清洗：`rocketLaunch`、`Icons.home`、`material:home` 会被自动纠正。
- 仅支持 `material:` 库前缀；`fontawesome:github` 等其他库会回退到 `Icons.extension` 并输出警告。
- 非法名称会输出：

```text
[Plugins] 非法或不支持的图标名称：'xxx'，请使用全小写蛇形命名（如 'home', 'settings'）。
```

## 示例

```json
{ "icon": "skip_next" }
```

```json
{ "icon": "material:settings_suggest" }
```
